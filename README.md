# 🛡️ FinGuard – Learn Smart, Stay Safe

FinGuard is a bilingual financial literacy and scam-awareness website designed to help people understand financial concepts and stay safe from online scams.

## 🌟 Features

- Telugu and English language support
- Financial learning resources
- Scam awareness and prevention tips
- Interactive investment safety checker
- Scam Spotter Challenge
- Interactive quiz with scoring
- Indian cybercrime and SEBI resources
- Responsive desktop and mobile design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 Project Objective

To improve financial awareness, encourage safe digital practices, and help users identify common online financial scams.
